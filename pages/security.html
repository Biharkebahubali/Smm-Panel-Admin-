💡 Password Tips

✅
Use 12+ characters — longer is stronger
✅
Mix case, numbers & symbols — like My#Pwd2024
✅
Use unique password — never reuse from other sites
❌
Don't use birthdays — or common words
❌
Never share password — even with "support"

📋 Current Hash

${CONFIG.MASTER_PASSWORD_HASH || 'Not configured'}

🛠️ How to Change Password Manually

  1. Generate SHA-256 hash of new password using:
    crypto.subtle.digest('SHA-256', new TextEncoder().encode('YOUR_NEW_PASSWORD')).then(b => console.log([...new Uint8Array(b)].map(x=>x.toString(16).padStart(2,'0')).join('')))
  2. Copy the hash output
  3. Open config.js and replace MASTER_PASSWORD_HASH value
  4. Save file and reload admin panel
  5. Login with new password
